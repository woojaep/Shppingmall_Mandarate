# 온라인 쇼핑몰 BUSINESS 만다라트

> **쇼핑몰 만다라트로 모든걸 자동화 하자!**

온라인 쇼핑몰 사업 전체 구조를 한 화면에서 보고, 각 업무의 **자동화 상태**와 **자동화 우선순위**를 관리하는 웹앱입니다.
완성형 ERP나 실시간 대시보드가 아니라, **살아있는 사업 지도 + 자동화 로드맵**입니다.

무엇을 사람이 붙잡고 있고 무엇을 기계에 넘겼는지 한눈에 보이면,
다음에 자동화할 것이 저절로 드러납니다. 그 순서를 정하는 게 이 앱의 목적입니다.

## 화면 구조

```
판매        [상품/소싱] [마케팅] [고객/CS]
운영        [재고/물류] ★ ONLINE BUSINESS ★ [운영/시스템]
경영·미래   [재무/자금] [세무/회계] [전략/계획]
```

- 기본 seed: 대분류 8개 / 하위항목 64개
- 대분류 개수가 7개든 10개든 카드가 자동으로 줄바꿈되어 레이아웃이 깨지지 않습니다.
- 중심 카드는 대분류 개수와 무관하게 운영 band 한가운데에 놓입니다.

## 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 대분류 상세 보기 | 카드 제목 클릭 → 오른쪽 상세 패널 |
| 항목 자동화 상태·우선순위 지정 | 상세 패널에서 항목 펼치기(▼) |
| 대분류/항목 추가·삭제·이름변경 | 상단 **편집 모드** 켜기 |
| 순서 바꾸기 / 다른 대분류로 옮기기 | 편집 모드에서 드래그 (⠿ 손잡이) |
| 항목을 대분류로 승격 | 상세 패널 → 항목 펼치기 → `대분류로 승격` |
| 층(판매/운영/경영·미래) 바꾸기 | 카드 하단 셀렉트, 또는 다른 band로 드래그 |
| 실수 복구 | 상단 `되돌리기` 또는 삭제 직후 뜨는 토스트 |
| 백업 / 복원 | 상단 `내보내기` / `불러오기` (JSON) |

- 상태 표시는 색 + 기호를 함께 씁니다: `●` 수동(빨강) · `◐` 반자동(노랑) · `○` 자동(초록)
- 우선순위: `★` / `★★` / `★★★`
- 상단 요약의 **"★★★인데 아직 수동"** 이 자동화 후보 1순위입니다.

## 데이터 저장

- 변경사항은 브라우저 **localStorage**에 자동 저장됩니다(디바운스 0.3초).
- 저장/불러오기는 `src/data/repository.ts`의 `BusinessMapRepository` 인터페이스 뒤에 있습니다.
  나중에 Supabase/Postgres로 옮길 때 이 인터페이스 구현체만 갈아끼우면 됩니다.
- 다른 PC로 옮기거나 백업하려면 `내보내기`로 받은 JSON을 `불러오기` 하세요.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성 (dist/index.html 은 더블클릭으로도 열립니다)
npm run smoke    # 초기 렌더 + 이동/삭제/되돌리기 로직 점검
```

스택: Vite + React 19 + TypeScript + Tailwind CSS v4 + dnd-kit

## 폴더

```
src/
  types/model.ts              도메인 타입과 라벨
  data/seed.ts                기본 8개 대분류 / 64개 항목
  data/repository.ts          저장소 인터페이스 (교체 지점)
  data/localStorageRepository.ts
  data/normalize.ts           저장/불러온 JSON 방어적 정규화
  store/                      reducer + Context (모든 변경의 단일 통로)
  lib/                        집계·필터·색토큰·JSON 입출력
  components/                 화면
```
